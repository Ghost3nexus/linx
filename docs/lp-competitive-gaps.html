2. 初版から変わった結論が2つ

論点初版で書いたこと正しくはこう
料金の開示「6社中、開示は GoHighLevel だけ。開示は強い差別化」この領域では非開示が主流。SimplyBook も Trafft も金額を出さず個別相談に寄せる。開示しているのは SuperSaaS(20%引き)と GoHighLevel。開示が少数派なのは変わらないので差別化にはなるが、「珍しい」の度合いは初版ほどではない
自社開発との比較表「FC本部の最大の代替案なのに無い。作るべき」優先度を下げてよい。SimplyBook も Trafft も持っていない。この領域の定石ではなかった。作るなら開発費の実額を積んでからで、急ぐ話ではない

3. 同カテゴリと比べて抜けている点（重い順）

#点競合が実際にやっていることLINXの現状と直し方
1デモアカウントを配っていないTrafft はデモアカウントを5個渡す。代理店が商談の場で「御社のブランドで動く実物」を見せられる。SimplyBook も同じ思想で、通話前にガイドPDFを渡すうちは DEMO_LINE_URL が null で「デモ環境のご案内を受け取る」止まり。白ラベルを売るのに、配れるデモが無いのは致命的。デモ用LINE公式アカウントを1本作って、契約前の代理店に渡す
2増やす動機が価格構造に無いTrafft は 1-5／6-15／16-30／31-50／51+ で段階的に安くなる。GoHighLevel は固定費なので増やすほど利幅が広がる。どちらも「増やすほど得」が構造に入っているうちは1店舗¥5,000固定。20店舗でも100店舗でも1件あたりの旨みが同じ。案4の固定枠¥50,000は用意してあるが、LP上で階段になっていない。卸値を店舗数で逓減させる表をLPに出す
3回収の目安が無いSimplyBook「20社未満で回収」、GoHighLevel「3社でプラン費用を回収」。この領域の定番の見せ方うちの卸値型は固定費が無いので数学的な損益分岐は存在しない。代わりに「代理店の営業コストを何社で回収できるか」を出す。固定枠型には既に損益分岐店舗数が出ているので、それを前に出す
4商談予約の導線が無いSimplyBook も Trafft も "Book A Demo" でカレンダーに直結。SimplyBook は資料DLより商談予約を主CTAにしているうちは資料請求フォームのみ。この単価帯のB2Bは、資料より打ち合わせのほうが速い。カレンダー予約を主CTAに足す
5導入までの流れと期間が無いSimplyBook「数週間で開始」＋4段のオンボーディング。Trafft は5段。使えるねっとは「約1〜1.5ヶ月」初版と同じ指摘だが、競合が実際に何段で何週間と書いているかが取れた。4〜5段＋各段の日数で置く
6用語の違いを説明していないSimplyBook はFAQ7問の1問目が「ホワイトラベル / 代理店 / アフィリエイト の違い」うちのFAQ10問に無い。相手が最初に混乱する点なので1問目に置く
7クライアント作成APIに触れていないTrafft は「Client creation API」を売りにしている。代理店が自社の画面から店舗アカウントを作れるかロードマップに「パートナー管理画面は未実装」とは書いたが、APIの有無に触れていない。できるなら書く、できないなら現状を書く
8レビューサイトに載っていないTrafft は Capterra・G2・Trustpilot・GetApp を並べる日本なら ITreview / BOXIL / PRONIアイミツ。掲載用の原稿は docs/saas-listing-content.md に既にあるが未掲載、かつ内容が古い（Free¥0・Lステップ比較・hacomono¥35,000/店＝いまの¥19,800体系と合わない）。直してから出す
9セキュリティの事実が無いDuda は CTA直下に ISO 27001・GDPR・99.99% uptime。SimplyBook は GDPR・HIPAA。使えるねっとは AES-256実測でパートナーLPに AES-256 も SSL も0件。/product には各2件ある。実績ゼロでも言える事実なので、載せない理由がない
10審査基準が無いのに絞ると書いているSimplyBook は逆に応募要件を一切書かず、対象を3種（エージェンシー／FC・多店舗／技術ベンダー）示すだけで個別相談に寄せているうちは「誰にでも卸すわけではありません」と書いた。絞ると言うなら基準が要る。言わないなら対象像だけ示す。どちらかに寄せる

4. 崩してはいけない点

点同カテゴリと比べて
動かせる収益シミュレーターSimplyBook は固定の数字（€100,000+ / 90% / 300%）、Trafft は段階表、GoHighLevel は静的な表。相手の商圏の数字で試算させるのはうちだけ
できないことの明示6社のどこもやっていない。実績が無い会社が信用を作る、ほぼ唯一の手
実際の管理画面使えるねっとは製品画面を1枚も出さない。SimplyBook も画面より数字。うちは4枚出したうえで「データはサンプル」と断っている
白ラベルの3面比較「御社の名前で売れる」を文章でなく実物で見せている。Duda が製品UIでやっていることの白ラベル特化版
卸値と従量の全面開示この領域では非開示が主流。実績ゼロのうちは、開示以外に注意を引く手が無いので、この選択は維持でよい

5. 手をつける順番
